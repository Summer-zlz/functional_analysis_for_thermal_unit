# DeNOTS and APN Reproduction

## Files

| File or directory | Description |
|---|---|
| `run.py` | Main entry point. |
| `training.py` | Training, rolling validation, and parameter selection. |
| `data_loader.py` | Trajectory loading, splitting, and normalization. |
| `official_models.py` | DeNOTS and APN regression interfaces. |
| `evaluate.py` | MAE, RMSE, and MAPE calculations. |
| `bootstrap.py` | Paths and automatic source extraction to a temporary cache. |
| `author_sources.zip` | Only the required official model source files and available notices. |
| `sources.json` | Source repositories and pinned commits. |
| `requirements.txt` | Python dependencies. |
| `data/` | Three input datasets. |
| `results/` | Supplied metric summaries and selected hyperparameters. |

## Running

Use a compatible Python environment (Python 3.9 recommended):

```powershell
cd DeNOTS_APN_reproduction
python -m pip install -r requirements.txt
python run.py
```

Choose the PyTorch build appropriate for your hardware. No dependencies are bundled; use an isolated environment to avoid conflicting installed versions.

The complete run performs rolling validation and independent testing, followed by all-sample group fitting. Detailed outputs are generated in `rerun_results/`. Supplied summaries in `results/` are preserved.

Optional individual stages:

```powershell
python run.py --stage rolling
python run.py --stage direct
python run.py --stage verify
```

Run `rolling` before `direct`. Verification requires the checkpoints generated by a completed run. Use `--output PATH` to select another output directory.

Full archived checkpoints, predictions, dependencies, and documentation are retained separately in `../DeNOTS_APN_archives/complete_package/`.
